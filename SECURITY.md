# Security policy

## Supported versions

Only the latest release of Lirelle receives security fixes.

## Reporting a vulnerability

Report a vulnerability privately, through GitHub: on the repository's **Security** tab, choose **Report a
vulnerability**. Never open a public issue for it, and do not discuss it in public until a fix is out.

Say what the vulnerability is, how to reproduce it (the app's version, the device and Android version, the server and
its version), and what an attacker could do with it.

## What is in scope

The Lirelle app and the code in this repository. Vulnerabilities in the BookOrbit or Komga servers themselves belong
to those projects: report them there.

## What happens next

Lirelle is a volunteer project, so this is done on a best-effort basis:

1. the report is acknowledged;
2. the vulnerability is confirmed, and a fix is prepared in private;
3. a release with the fix is published;
4. the vulnerability is then disclosed in a GitHub security advisory, crediting the reporter if they wish.
